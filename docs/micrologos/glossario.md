# Glossário

| Termo | Significado (no contexto do Micrologos e da saúde no Brasil) |
|---|---|
| **ANS** | Agência Nacional de Saúde Suplementar, que regula os planos de saúde e define o padrão TISS |
| **APAC** | Autorização de Procedimentos Ambulatoriais (SUS), para procedimentos de alta complexidade/custo |
| **Arquétipo** | Perfil (de paciente ou de ficha) que define quais campos ou fichas de dados se aplicam |
| **BPA** | Boletim de Produção Ambulatorial (SUS) |
| **Brasíndice** | Tabela de referência de preços de medicamentos e materiais |
| **CBHPM / AMB** | Tabelas de honorários e procedimentos médicos |
| **CFM / CRM** | Conselho Federal / Regional de Medicina; "Consultar CFM" valida o registro do médico |
| **CID-10** | Classificação Internacional de Doenças |
| **CIHA** | Comunicação de Informação Hospitalar e Ambulatorial (SUS), obrigatória para prestadores |
| **CNS** | Cartão Nacional de Saúde (cartão SUS) |
| **Classificação de guia** | Agrupamento interno usado para separar contas e guias no faturamento e nos lotes |
| **Conta do paciente** | Conjunto de itens faturáveis de um atendimento (procedimentos, mat/med, honorários, taxas) |
| **Convênio mestre** | A operadora; os "convênios/planos" são os produtos dela |
| **DICOM / PACS** | Padrão de imagens médicas / servidor de armazenamento dessas imagens (Orthanc no Micrologos) |
| **DML** | Base de medicamentos usada na prescrição (mais de 40 mil itens) |
| **DMED** | Declaração de Serviços Médicos e de Saúde (Receita Federal) |
| **DRE / DFC** | Demonstração do Resultado / Demonstração do Fluxo de Caixa |
| **Emitente** | No Cash: cadastro único de cliente ou fornecedor (pessoa física ou jurídica) |
| **Esp. Pend.** | Status de agenda "espera pendente" |
| **Desmembrado** | Agendamento dividido em mais de um (por exemplo, vários procedimentos) |
| **Ficha de dados** | Formulário configurável do PEP (campos, limites, cálculos) |
| **Glosa** | Valor recusado pelo convênio no pagamento; pode ser **técnica** (clínica) ou **administrativa**; cabe recurso |
| **GED** | Gestão eletrônica de documentos (anexos) |
| **Kit** | Conjunto de produtos ou procedimentos lançado de uma vez |
| **Laudo** | Relatório médico de exame, que pode ser assinado digitalmente e liberado no portal |
| **NFS-e Nacional** | Nota Fiscal de Serviço eletrônica no padrão nacional |
| **ONA** | Organização Nacional de Acreditação (qualidade hospitalar) |
| **OPME** | Órteses, Próteses e Materiais Especiais |
| **PEP** | Prontuário Eletrônico do Paciente |
| **Plano financeiro** | Plano de contas do Cash |
| **Portador** | No Cash: conta bancária, caixa ou carteira por onde o dinheiro passa. No Clinic, também aparece ligado ao paciente (carteirinha) |
| **Repasse** | Valor devido ao médico pela produção (honorários), calculado sobre o que foi faturado e/ou recebido |
| **SP/SADT** | Guia TISS de Serviço Profissional / Serviço Auxiliar de Diagnóstico e Terapia (exames, procedimentos) |
| **Staff médico** | Cadastro dos profissionais que atendem |
| **Taxa de turno** | Adicional cobrado conforme o turno ou horário do atendimento |
| **TISS / TUSS** | Padrão de troca de informações com as operadoras / Terminologia Unificada (códigos de procedimentos) |
| **Totem** | Terminal de autoatendimento na recepção (senha, chegada) |
| **URA** | Unidade de Resposta Audível (menu telefônico automático) |
